paths.py -- how it finds your data
----------------------------------
The original DB filename and scan-output directory name do not survive anywhere
in this package, so paths.py DISCOVERS them rather than guessing:

  * data root: %APPDATA%\SponsorScout  (documented in seed_manager, ats_scanner
    and career_scanner, and in the install steps above)
  * database:  an existing *.db / *.sqlite* in the data root if the default
    sponsorscout.db is absent; the most recently modified one if several exist
  * scan output: an existing directory holding *_career_jobs*.csv,
    *_scan_log.csv or *quarantine.csv

Every choice is printed to stderr on first import. If it names the wrong file,
pin it explicitly -- these four environment variables always win:

    SPONSORSCOUT_DATA_DIR          app data root
    SPONSORSCOUT_DB_PATH           SQLite file
    SPONSORSCOUT_SCAN_OUTPUT_DIR   where scan CSV artefacts are written
    SPONSORSCOUT_SEEDS_DIR         mutable per-user seed copies
